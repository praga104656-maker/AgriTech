# AgriTech

AgriTech is a smart farmer-to-consumer agricultural marketplace.

## Project Goal

The platform connects farmers directly with consumers and business buyers while providing smart insights for pricing, demand, supply and logistics.

## Main Modules

- Farmer Marketplace
- Buyer Marketplace
- Smart Price Engine
- Demand Prediction
- Weather Information
- Farmer Clustering
- Buyer Requirement Matching
- Order Management
- Logistics and Tracking
- AI/ML Predictions

## Technology Stack

### Frontend
HTML, CSS, JavaScript

### Backend
Java, Spring Boot, REST API

### Database
MySQL

### AI/ML
Machine Learning / Python
